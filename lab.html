What actually runs

Two libraries compiled from this repo, imported by bare specifier in src/main.js.

  • gsap file:vendor/gsap → esm/index.js · 3.15.0
  • lenis file:vendor/lenis → dist/lenis.mjs · 1.3.27
  • ScrollTrigger pin, scrub, snap — used by this page
  • SplitText per-word stagger on the headline

Run it again

npm install
npm run dev        # vite, host 0.0.0.0
npm run build      # static output
npm run build:lenis   # rebuild smooth scroll
# from source after editing
